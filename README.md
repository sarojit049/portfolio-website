## 🌟 Overview

This portfolio website serves as a professional digital presence for **Saroj Kumar**, highlighting technical expertise, software development projects, certifications, achievements, academic background, and work experience.

The portfolio is designed to provide recruiters, hiring managers, internship coordinators, and collaborators with a comprehensive view of my skills and accomplishments through an engaging and modern user experience.

### 🎯 Objectives

* Showcase technical projects and achievements
* Demonstrate frontend and backend development skills
* Present certifications and academic qualifications
* Provide an easy way to connect through a contact form
* Maintain a professional online presence

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/sarojit049/portfolio-website.git
cd portfolio-website
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```
